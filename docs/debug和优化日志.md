# 4estDS 系统 Debug 与算法优化日志

本文档记录 4estDS 系统在真实数据与业务场景落地过程中，遇到的各类底层地理空间算法、三维点云融合、瓦片渲染及前后端性能等关键问题的深度排查复盘与优化方案。

## 2026-09-15 珠金平幼树树高失真与冠幅面积缩水深度排查及优化方案

### 1. 业务现象与问题背景
在珠海市金湾区珠金平（时相 `20260809`，正射影像 `result_cog.tif`）的单木点云高程融合分析中，肉眼比对与数据呈现以下三大异常矛盾：
1. **相邻幼树树高反转**：
   - 右上角小树（`obs_7a5322f81a35`）在正射影像中尺寸小且位于裸地，系统计算高度却高达 **1.55 m**；
   - 左下角小树（`obs_4f0335179db4`）肉眼观察更为高大茂盛（位于杂草丛中），系统计算高度却仅有 **0.22 m**；
2. **冠幅面积估算与真实面积悬殊**：
   - 单木 `obs_764b1d878344` 的估算冠幅面积（`crown_area_geo_est`）为 **0.68 ㎡**，但真实冠幅面积（`crown_area_geo_real`）仅记录为 **0.19 ㎡**，相差达 3.6 倍。

### 3. 根本原因剖析

#### 根因一：草丛假地面导致基底抬高（左下角树低估至 0.22m）
- 激光雷达波长与穿透力有限，大量激光被茂密草丛表面截留；
- 大疆智图等点云分类算法将高程在 `1.23m ~ 1.30m` 的密草表面反射误划分为 **Class 2（地面点）**；
- 原算法通过 KD-Tree 仅取最近 3 个 Class 2 点做反距离加权（IDW）插值，直接将草尖（`1.237m`）算作单木树根基准；
- 真实泥面位于 `0.92m`，草丛将基底拔高了 `0.31m`，小树被草丛“吃掉”近六成株高：$1.456\text{m} - 1.237\text{m} = \mathbf{0.22\text{m}}$（实际株高应为 $\mathbf{0.52\text{m}}$）。

#### 根因二：代码盲取最大值，被高空断层噪点拉高（右上角树虚高至 1.55m）
- 右上角树在 Z 轴垂直分布上存在**严重物理断层**：
  - `0.9m ~ 1.58m` 集中了 171 个密集连续点（属于真实树体，树顶约 1.58m，实际高度约 0.60m）；
  - `1.6m ~ 2.1m` 的 50 厘米高程范围内**绝对点数为 0（空气断层）**；
  - `2.13m ~ 2.58m` 突然出现 18 个悬空点（水平跨度仅 14cm×20cm，疑似测量标杆、细竹竿或悬浮噪点）；
- 原算法直接采用 `h = np.max(valid_h)`，盲目截取了 2.58m 孤立点，导致树高得出 $2.58\text{m} - 1.03\text{m} = \mathbf{1.55\text{m}}$ 的严重虚高。

#### 根因三：点云欠采样孔洞无填补（真实面积被系统性腰斩）
- 185 点/㎡ 的航测点云无法保证 5cm 栅格（需 400 点/㎡）全覆盖，天然存在 40%~50% 的空洞网格（NaN）；
- 原算法将树冠内部因脉冲采样间隔产生的无点格网**直接当做非树冠剔除**；
- 估算面积用矩形外包框 $W \times H$（包含四个角落的裸泥与空隙），真实面积用镂空点云格网，两者产生 3~4 倍割裂。

### 4. 优化实施方案

#### 改造 1：宏观泥面感知与假地面点剥除（基底校准）
在 `chm_from_las` 中，对所有 Class 2 地面点引入大尺度分位数滤波：
1. 以 `10m ~ 15m` 格网对地块进行粗划分，计算各粗格网内 Class 2 点的 $P_{10}$（10分位数）作为泥面基准；
2. 剔除高出局部泥面基准 $> 12\text{cm}$ 的草丛假地面点，仅保留真正的平整泥面骨架点构建 KD-Tree 插值；
3. **效果**：草丛区地面基准自动恢复到真实泥滩标高（约 0.95m~1.00m），左下角小树树高恢复为正常的 0.45m~0.52m。

#### 改造 2：垂直连续性断层截断滤波（抗孤立悬空噪点）
在 `metrics_for_detection` 中，自下而上检测树冠垂直高度连续性：
1. 沿 Z 轴检测点云间距；若在连续树冠上方出现 $> 35\text{cm}$ 的绝对点云空洞断层（Gap），判定树冠在断层处已自然结束；
2. 截断抛弃断层上方的浮空噪点，锁定连续植物主体的真实最高点；
3. **效果**：杜绝细竹竿、飞鸟或悬浮多路径噪点导致的单木高度暴增，右上角树高由 1.55m 修正为真实的 0.60m。

#### 改造 3：形态学二值闭合弥合欠采样孔洞（修复真实面积缩水）
在 `metrics_for_detection` 中，对有效高度掩模执行形态学闭合与孔洞弥合：
1. 结合 `scipy.ndimage.binary_fill_holes` 与 8 邻域支撑插补（填补周围 $\ge 4$ 个有效树冠像元的脉冲采样空洞）；
2. 仅闭合树冠内部由于点云脉冲间隔造成的 1~2 个像元（5~10cm）的小空隙，绝不外扩蔓延至外框角隅的裸地；
3. **效果**：`obs_764b1d878344` 的真实冠幅面积合理恢复至 0.35㎡ 左右，解决因点云稀疏带来的系统性面积低估。
