为了实现对 **T-Rex Label** 这种工业级 AI 辅助标注系统的“极其精细的复刻”，我们需要脱离单纯的“网页截图”思维，将其拆解为一个**重度依赖状态管理和富交互（Canvas）的单页应用（SPA）**。

下面我将从 UI 架构、核心模块交互、隐藏状态逻辑以及技术栈选型四个维度，为你提供一份用于完美复刻的深度剖析总结。

### 一、 UI 架构与视觉规范 (全局骨架)

该系统采用了经典的“IDE 风格”五区块布局，视觉上注重沉浸感与数据的清晰呈现。

* **色彩规范 (Dark Mode)：**
* **背景色：** 整体采用深灰色调（大致在 `#18181B` 到 `#27272A` 之间，类似于 Tailwind 的 `zinc-900`）。
* **强调色 (Accent)：** 交互激活状态（如选中的工具、当前的类别图标、按钮）采用了青色/蓝绿色（Teal/Cyan，类似 `#2DD4BF`）。
* **标注色：** 当前画布上的 Bounding Box（边界框）使用亮蓝色（`#3B82F6`），保证在高复杂度图片底色上的高对比度。


* **布局逻辑 (CSS Grid / Flexbox)：**
* 顶部导航栏（固定高度，如 `48px`）。
* 中间区域采用 Flex/Grid 布局：左侧工具栏（固定宽度，如 `48px`），中间画布区（自适应 `flex-1`，居中溢出隐藏），右侧属性面板（固定宽度，如 `280px` 或 `320px`）。
* 底部缩略图栏（固定高度，如 `80px`）。

### 二、 核心功能模块精细剖析

#### 1. 左侧工具栏 (Tools - 状态机控制器)

这是整个编辑器的心脏，决定了当前用户在 Canvas 上的交互模式。复刻时，这里本质上是一个**状态机（State Machine）**。

* **基础工具：** 鼠标指针（选择/拖拽已画好的框）、多边形工具（Polygon）、矩形框工具（Bounding Box）。
* **AI 辅助工具（核心亮点）：** 带有 `AI` 角标的魔棒工具（可能是点击物体自动分割）和带星号的框选工具（可能是 T-Rex 的交互式视觉提示框）。
* **操作历史：** 撤销（Undo）、重做（Redo）、删除（Delete）。
* **视图控制：** 帮助、网格辅助线、设置选项、放大、缩小、当前缩放比例指示（如图中的 `52%`）。

#### 2. 中央画布区 (Workspace Canvas)

这是工程量最大的区域，绝对不能用普通的 DOM 堆叠来实现。

* **底层：** 渲染目标图像（`xuwen_1024px.jpg`）。
* **交互层：** 叠加在图片上的 Canvas 元素。需要支持：
* 鼠标滚轮缩放（以鼠标当前位置为中心的 Zoom in/out）。
* 空格/中键按住时的画布平移（Pan）。
* **绘制与编辑：** 鼠标按下拖拽生成蓝色边框的矩形，框的四个角和四条边需要有控制点（Handles），支持二次拖拽改变大小。



#### 3. 右侧属性与标注面板 (Inspector Panel)

这个面板负责展示数据的“事实来源”（Source of Truth），必须与中央画布**严格双向绑定**。

* **图片信息 (Accordion 折叠面板)：** 只读状态，展示文件名、分辨率（1024x1024）、格式和大小。
* **标注列表 (Annotations)：**
* **层级结构：** 按类别（如 `TREE`）分组，右侧有数量徽章（如 `3`）。展开后应列出该类别下的具体每一个框（#1, #2, #3）。
* **快捷操作：** 提供全局显示/隐藏图标（眼睛）和单独类别的隐藏功能。



#### 4. 顶部与底部状态栏

* **顶部 (Global Actions)：** 当前激活类别下拉菜单（选中的是 TREE）、分页控制器（`< 1/1 >`，处理多图任务）、统计与导出功能。
* **底部 (Thumbnail Gallery)：** 图片画廊，左侧提供漏斗（筛选类别）和新增按钮，右侧显示带有当前标注微缩状态的图片缩略图。

### 三、 隐性交互与弹窗逻辑 (根据上下文提取)

从你提供的文本数据中，可以捕捉到截图中未直接展示但真实存在的**隐藏弹窗和 AI 处理流**，复刻时不能遗漏：

1. **AI 自动检测弹窗 (Auto-detect Modal)：**
* 包含“置信度”调节滑块（Confidence Threshold）。
* 显示“检测数量”（Detection Count）。
* 包含复选框选项：“在所有图像中自动检测此类别”（批量处理功能）。


2. **分割完成确认：**
* “完成当前分割 [确 认] [取 消]” —— 这说明系统不仅仅做矩形框检测，可能还包含了 SAM (Segment Anything) 等多边形/Mask 像素级分割的确认逻辑。

### 很重要的交互逻辑

支持两种标注模式：
- `交互式AI标注`：用户指定好种类，然后在图上每画一个框，就会触发一轮全图推理，并告知用户此次推理的结果
- `AI预标注`：通过文本prompt先给图像推理一波，再进入交互式AI标注

### 四、 完美复刻的“技术栈选型建议”

要达到极其精细的程度，你需要一套能扛住复杂状态和重度渲染的现代化全栈配置：

* **前端框架：** **React 18+** 或者 **Vue 3** (推荐 React，因为相关标注生态更好)。
* **UI 组件库：** **Shadcn UI** 配合 **Tailwind CSS**。Shadcn 能让你拥有极致的定制权，完美复刻原站的深色主题和精细的边框/阴影。
* **核心画布 (Canvas)：** 强烈推荐使用 **Konva.js (或 React-Konva)** 或者 **Fabric.js**。千万不要手写原生 HTML5 Canvas 逻辑，Konva/Fabric 原生支持对象拖拽、缩放、层级管理。
* **状态管理：** **Zustand** (React)。画布的坐标、右侧的列表、底部的缩略图需要共享一个庞大且更新频繁的 JSON State，Zustand 性能极佳且代码简洁。
* **快捷键库：** **react-hotkeys-hook**（支持空格拖拽、Ctrl+Z 撤销等 IDE 必备快捷键）。
