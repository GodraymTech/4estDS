## 阅读顺序

第一次接触项目:

1. 读 [快速开始](快速开始.md) 跑通环境。
2. 读 [项目工作原理](项目工作原理.md) 理解数据怎么流。
3. 按 [完整教程](完整教程.md) 做一次完整推理、报告、导出和前端联调。
4. 需要改数据库或报表时，再读 [数据表设计与工作机制](数据表设计与工作机制.md)。

做代码修改:

1. 先确认修改属于 CLI、API、Worker、前端、推理内核、数据库哪一层。
2. 优先复用现有边界: `service.py` 管 run 生命周期，`tasks/` 管业务编排，`engine/` 管推理内核，`db/reader.py`/`db/writer.py` 管读写。
3. 修改后至少跑 `uv run pytest tests -q`；前端改动还要跑 `mise exec -- pnpm run typecheck` 和 `mise exec -- pnpm run build`。
