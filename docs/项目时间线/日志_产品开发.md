
# 产品路线图

| 步骤 | 内容 | 产出 |
| --- | --- | --- |
| **① 需求与场景** | 拆解政府 vs 企业客户到底买什么、为什么买、谁付钱 | 客户画像 + 核心场景清单 |
| **② 业务流程** | 定义"数据进 → 价值出"的标准作业流程 | 端到端业务流程图 |
| **③ 产品定位** | 是否升级为"红树林数字化管理平台"及如何分层包装 | 产品定位与价值主张 |
| **④ 功能体系** | 功能模块分层（检测/分割/变化/碳汇/报告/管理） | 功能架构 + 优先级 |
| **⑤ 商业模式** | 定价、交付形态（SaaS/私有化/项目制）、客户成功 | 商业模式画布 |
| **⑥ 软件工程** | 从原型到可交付系统的技术架构演进 | 技术架构与演进路线 |
| **⑦ 售后与交付** | 实施、培训、运维、SLA、数据安全合规 | 售后体系设计 |
