# 4estDS 目标检测模型架构对比白皮书

本白皮书旨在全面对比当前主流及前沿的实时检测模型、多模态大模型以及交互式开放集模型，评估其在林业单木智能检测（4estDS 场景下的超大图切片、密集单木重叠、稀有树种检测、无标注冷启动等）中的适用性与技术表现。

---

## 一、 模型家族核心定位

### 1. 传统/实时回归流 (Real-Time Regressors)
* **YOLO12**: 融合了局部 Attention 机制的轻量 CNN 架构，相较于先前版本具有更强的表征能力，是目前 4estDS 的默认检测骨干。
* **YOLO26 / YOLOE-26** (2026年1月发布): 统一的端到端实时视觉模型，在框架内融入了**原生 NMS-Free（免去非极大值抑制）**设计，消除了后处理计算瓶颈；YOLOE-26 支持通过文本/图像 Prompt 进行开放词汇零样本检测。
* **RT-DETR** (Real-Time DETR): 首个真正意义上的实时端到端 Transformer 检测器，利用 Query 机制直接预测坐标，原生去除了 NMS 延迟，在密集重叠场景下表现极为出色。
* **RF-DETR** (Roboflow DETR, 2026年发布): 结合 DINOv2 强预训练骨干网的实时 DETR。利用**权重共享神经网络架构搜索（Weight-Sharing NAS）**，可以在不经历昂贵的全量训练下自动调优在特定数据集上的精度与延迟表现，COCO 精度首破 60 mAP，商业友好 (Apache 2.0)。

### 2. 交互式/开放集流 (Open-Set & Prompt-driven)
* **T-Rex2 / T-Rex-Omni**: 交互式开放集检测代表。
  * **T-Rex2**：同时融合了文本 Prompt（如 *"pine tree"*) 和视觉 Prompt（如框选一个树冠示例），支持通过少样本或零样本进行交互式框选计数（Count Anything）和自动数据集标注。
  * **T-Rex-Omni**：引入了**负向视觉提示（Negative Visual Prompts）**机制，通过 suppress/hinge 损失抑制类似灌木、杂草等困难负样本（Hard Negatives）的误检。

### 3. 自回归多模态大模型流 (Autoregressive MLLM)
* **Rex-Omni** (2026年发布): 30亿参数的多模态大语言模型（基于 Qwen2.5-VL-3B）。
  * 摒弃了传统的坐标回归，将检测、REFER、指向等视觉任务离散化并统一建模为 **Next-Token Prediction（下一个 Token 预测）** 问题。
  * 支持以自然的对话式指令直接完成图像理解与单木定位，展现出极强的通用认知力，但由于参数量巨大，推理延迟较高。

## 三、 林业单木检测场景下的技术选型与落地建议

在我们的 [4estDS](file:///home/ray/rays/repos/4estDS) 业务流中，不同模型可以对应解决不同的核心痛点：

### 1. 痛点：新林区冷启动与“标注地狱” ➡️ 推荐选型：T-Rex2 / T-Rex-Omni
* **落地逻辑**：林木检测最昂贵的是**人工树冠勾绘（Annotations）**。使用 T-Rex2，算法人员在正射影像图上仅需通过 bounding box 框选 3~5 株样本树，或者输入描述，模型即可自动在整张超大图上批量检出类似树冠并完成标注。通过 T-Rex-Omni 还能增加“负向提示”（如标注“这是杂草，不是林木”），极大地加速了定制化林区数据集的建立。

### 2. 痛点：移动端/无人机“边飞边推” ➡️ 推荐选型：YOLO26
* **落地逻辑**：无人机边缘计算芯片（如 Jetson Orin Nano）算力有限。传统 YOLO 在面临林区动辄成千上万个树冠检测框时，NMS 的 CPU 计算耗时可能比模型前向推理还长。YOLO26 原生 NMS-Free 的特性，使得切片推理的吞吐量大幅提升，可以实现无延迟的超轻量化边缘飞推。

### 3. 痛点：超复杂森林遮挡与多重灾害分析 ➡️ 推荐选型：RF-DETR
* **落地逻辑**：对于需要极高精度的商业采伐评估，RF-DETR 利用其 Weight-Sharing NAS 机制，可以仅针对特定林场树种做一次高效子网络架构搜索，直接提取出当前硬件上精度与吞吐量最均衡的定制 DETR 模型。同时，利用 DINOv2 骨干网强大的泛化能力，可以在不重新训练的前提下，对复杂多变的林木冠幅、枯死病害木保持极高的识别稳定性。

### 4. 痛点：智能林业助手与交互式报告 ➡️ 推荐选型：Rex-Omni
* **落地逻辑**：作为一个 3B 的多模态大模型，Rex-Omni 难以用于工业级实时像素切割，但它非常适合作为**“林场智能对话系统”的后端**。用户可以直接上传航拍影像并提问：“帮我数一下图片下方有多少株松树，并指出最高的几株在哪里”，模型可以直接生成文字描述并提供精确的定位 Token，极大地提高了最终报告交互的智能化体验。
