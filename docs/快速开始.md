# 快速开始

本文目标是用最少步骤把 4estDS 在本机跑起来。

## 环境要求

- Python 3.12+
- `uv`
- Node.js/pnpm 由 `mise` 管理
- 可选: Redis，用于前端任务中心的异步推理队列
- 可选: CUDA/GPU 和真实模型权重，用于 `ultralytics` 真实推理

## 1. 后端安装

在项目根目录执行:

```bash
uv sync --all-extras
uv run 4estds --help
uv run 4estds db init
```

如果只是本地命令行验证，可先用:

```bash
uv sync --extra detect --extra geo
```

## 2. 无 GPU 冒烟推理

```bash
uv run 4estds infer data/多源数据研究_徐闻/DOM/xuwen_1024px.jpg --arch mock --no-draw-box --export-format geojson
```

预期结果:

- `~/.4estDS/db/4estds.sqlite` 中出现 run、tract、tree_observations 记录。
- `~/.4estDS/logs/` 中出现带 run_id 的日志。
- `~/.4estDS/outputs/` 中出现报告和导出产物。

## 3. 真实影像推理

```bash
uv run 4estds infer path/to/ortho.tif --arch ultralytics --acquisition-time 20260706 --location demo-plot
```

常用参数:

```bash
--tile-size 1024
--overlap-rate 0.1
--chm path/to/chm.tif
--dsm path/to/dsm.tif --dem path/to/dem.tif
--las path/to/cloud.las --las-grid-size 0.05
--draw-box / --no-draw-box
--export-format geojson
```

`acquisition_time` 不传时，系统会尝试从影像元数据/文件信息提取；仍无法得到时回退到 `00000000`。

## 4. 启动 API

```bash
uv run uvicorn forestds.api.main:app --reload --host 127.0.0.1 --port 8000
```

检查:

```bash
curl http://127.0.0.1:8000/health
curl http://127.0.0.1:8000/api/v1/tracts
```

## 5. 启动前端

```bash
cd web
mise exec -- pnpm install --config.store-dir=/tmp/forestds-pnpm-store
mise exec -- pnpm run dev
```

打开 `http://127.0.0.1:5173`。开发环境中 `/api` 会代理到 `http://127.0.0.1:8000`。

## 6. 启动 Worker

前端 `/tasks` 提交异步推理时需要 Redis + Dramatiq:

```bash
redis-server
REDIS_URL=redis://localhost:6379/0 uv run dramatiq forestds.worker.actors --processes 1 --threads 1
```

保持单进程单线程是为了让 GPU 队列串行执行，并复用 worker 进程内缓存的检测器。

## 7. 开发校验

```bash
uv run pytest tests -q
cd web && mise exec -- pnpm run typecheck
cd web && mise exec -- pnpm run build
```

如果 pnpm 缓存权限不稳定，使用:

```bash
cd web
mise exec -- pnpm install --config.store-dir=/tmp/forestds-pnpm-store
```
